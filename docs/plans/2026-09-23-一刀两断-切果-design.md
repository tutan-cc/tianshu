# 新小游戏设计 · 「一刀两断」（街机切果）

> **状态**：设计已确认（纯街机版 · 完整版三模式 · 入场 ¥20）
> **参考**：`openvglab.github.io/.../svg/fruit-slash.svg`（水果忍者式单文件 SVG 小游戏）
> **目标仓库**：`tutan-cc/tianshu` · 分支 `JL` · 基线已合并 main（`e89782f`）
> **一句话**：老城区夜市摊上的一台切果机 —— 挥刀切开满天水果，别碰炸弹。

---

## 一、定位：为什么是纯街机版

侧栏常驻的第三个小游戏（前两个：🎟 刮刮乐 = 纯运气、🪨 开窗 = 眼力 + 赌性）。
**它补的是"手速与反应"这个缺口** —— 四维里的**体魄**此前只有打斗 QTE 一个出口，
而打斗要等剧情到 D6；切果是随时可玩的反应力出口。

- **不接剧情、不占节点**，与刮刮乐/开窗并列，只接财富与成就
- **美术全部程序化 Canvas 绘制**，不搬参考实现的矢量素材（`SOURCES.md` 的纪律：
  每项素材写清来源与授权；且项目现有画风都是程序化生成的）

## 二、玩法

### 2.1 一局

```
水果从画面下方抛成抛物线 → 按住鼠标/手指划过
  → 判定：刀光轨迹线段 ∩ 水果椭圆 且 **滑动速度 ≥ 阈值**（太慢切不开）
  → 切开：分成两半，各带速度与旋转飞散，露出果肉截面
  → 漏掉（掉出画面）→ 经典模式扣命
```

### 2.2 三模式（同一套引擎，模式只是配置）

| 模式 | 胜负 | 炸弹 | 特殊果 |
|---|---|---|---|
| **经典** | 3 条命，漏 3 个结束 | **碰到立即结束** | 无 |
| **街机 60 秒** | 60 秒冲分 | 碰到 **−10 分** | **冰冻 / 双倍 / 狂热** |
| **禅意 90 秒** | 90 秒，静心切 | 无 | 无 |

三难度（简单/普通/困难）调：抛出间隔、同屏上限、炸弹比例、特殊果比例、初速。

### 2.3 计分

| 事件 | 分 |
|---|---|
| 切中一个水果 | +1 |
| 一刀切 ≥3 个（连击） | 额外 +3 |
| 极速正中（穿过中心区且刀速高） | 该果 +10（暴击） |
| 炸弹（街机） | −10 |
| 连斩 streak | 单独计数显示（不直接给分） |

### 2.4 特殊果（仅街机）

冰冻（时间流速 ×0.45，5 秒）· 双倍（得分 ×2，10 秒）· 狂热（抛出频率 ×2.2，10 秒）

### 2.5 与四维耦合

| 属性 | 接入 |
|---|---|
| **体魄** | 刀刃判定半径（挥刀容错） |
| **智慧** | 「定身」次数 `1 + ⌊智慧/25⌋`（上限 3），按空格减速 3 秒 |

## 三、经济（入场 ¥20，必须标定）

```
入场 ¥20（与刮刮乐、开窗小料同价）
结算 = payout(得分)，阶梯函数 → 落进财富
```

**两条不变量（写成测试，改数值必跑）**：
1. **乱切必亏**：随手乱挥（低命中、无连击）的长期期望 **< 0**
2. **手熟能赚但不失控**：高命中 + 连击的期望 **> 0 且有上限**

> 标定方式与「开窗」相同：纯规则层提供 `simulateGame()`，可在 node 里整局自动跑，
> 用蒙特卡洛标出分数分布，再定阶梯。

**成就**：【一刀两断】单刀切 ≥5 个 · 【刀客】单局 ≥300 分。

**练手局**：财富 < ¥20 时自动开一局不结算的练手局（同开窗）。

## 四、技术方案

### 4.1 模块形态

**独立模块 `slash.js`**（ES5 IIFE / `window.Slash`），与 `jade.js` / `breakfast.js` 同构：

```
slash.js
├─ 1. 调参区（TUNE / MODES / DIFFS / FRUITS 表）
├─ 2. 纯规则 rules（无 DOM，可整局自动跑）
│     rng · spawnWave · segHit（线段∩椭圆）· fastEnough · scoreOf · payoutOf · simulateGame
├─ 3. 渲染（Canvas：水果整/切两态 + 刀光 + 果汁粒子 + HUD）
│     水果按「皮壳风格 + 果肉风格」两张配方表复用绘制例程，10 种不写 20 个函数
├─ 4. 运行时（start / dispose / loop / 指针输入 / 暂停）
└─ 5. 对外 API：version · start · isBusy · dispose · rules · debug
```

### 4.2 必须同步的五处（照开窗踩过的坑）

1. `index.html` 加 `<script src="slash.js">`
2. **覆盖层 `#slash` 放 body 级 + `.overlay.side`** —— 侧栏面板放进 `#cine` 会因
   `display:none` 永久不可见（开窗那次事故的根因）
3. `tools/dev/stamp.js` 的文件表加 `{ file: "slash.js", tag: "sl" }`，水印也加 `sl` 段
4. `run-all-tests.ps1` 注册 `tests/slash.test.cjs`
5. 存档新增 `slashBest` / `slashRuns` / `slashNet`，**缺省即补**（旧档仍是合法档）

### 4.3 输入

指针事件（`pointerdown/move/up`，回退到 mouse + touch）· 空格 = 定身 · `P` 暂停 ·
覆盖层打开时吞掉全局空格推进（现有键盘处理已有 `.overlay.on` 守卫）
