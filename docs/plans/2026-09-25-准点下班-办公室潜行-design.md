## 二、本作的四条设计决定

### 1. 被发现：立即失败，但**已过的关不回退**

原作就是"被发现立即失败"，这是紧张感的来源，照做。但重来的粒度按原作定为**本关**
（`本关将从第一层重试，已通关的关卡保留`）—— 反复重打已经玩熟的关只会变成惩罚。

时限是**三关共用**的（原作是两层共用）：时间不会因为你被抓住而重置。
所以"被发现一次"的真实代价是**时间**，这比单纯的重复劳动有意思。

### 2. 掩体分两级：工位挡人又挡视线，隔板只挡视线

这是本作唯一在原型之外加的东西，也是让"路线"这件事有得算的关键：
工位是实心障碍（要绕），隔板是半高（能走过、但能挡住主管的视线）。
于是"沿着隔板背面的那条线走"成了可执行的技巧，而不是"离得远就行"。

### 3. 伪装是**限时免疫**，不是隐身

`文件夹` 打印区拾取，每关一份，按空格用掉，若干秒内不会被发现。
不做成"永久隐身"也不做成"用了就过关"——它是**一次性的穿视野通行证**，
要用在"必须穿过某个躲不掉的视野"的那一刻。

### 4. 咖啡机是**唯一能改变巡逻路线的动作**

`启动咖啡机` → 主管转向茶水间 → 几秒内那条路线空出来。
它把游戏从"纯躲避"变成"可以先改变棋盘"——这是原作里最聪明的一条机制，必须留。

## 三、技术方案

### 俯视网格 + 视野锥

零依赖、纯 canvas 2D、ES5（与仓库其它 5 个模块同构）。格子 40px，
关卡用**构建器 API** 描述（不是手数 ASCII —— 手数字符宽度必然会错，且改不动）：

```js
build: function (g) {
  g.border();
  g.fill(4, 3, 6, 4, "D");        // 工位：挡人 + 挡视线
  g.fill(10, 8, 14, 1, "p");      // 隔板：挡视线，能走过
  g.put(2, 5, "C");               // 咖啡机
  g.put(28, 4, "F");              // 文件夹
  g.put(15, 1, "E");              // 出口
  g.put(16, 17, "@");             // 出生点
  g.patrol([[6,6],[6,14],[20,14],[20,6]]);
}
```

地格类型：

| 符号 | 含义 | 挡人 | 挡视线 |
| --- | --- | --- | --- |
| `#` | 墙 | ✓ | ✓ |
| `D` | 工位桌椅 | ✓ | ✓ |
| `p` | 半高隔板 | ✗ | ✓ |
| `.` | 地板 | ✗ | ✗ |
| `E` | 出口（门 / 电梯） | ✗ | ✗ |
| `C` | 咖啡机 | ✓ | ✗ |
| `F` | 文件夹拾取点 | ✗ | ✗ |
| `L` | 茶水间（咖啡机引诱目标） | ✗ | ✗ |

**视线判定**是纯函数，与渲染无关：
`视线内 = 距离 ≤ range && |角度差| ≤ 半个 FOV && 连线上没有挡视线格`。
连线用 1/4 格步长的采样——比 Bresenham 简单，且在 40px 格子下精度绰绰有余。
**这条是整个玩法的心脏，所以它是纯函数、单测直接喂坐标验边界。**

### 巡逻：走 → 停 → 扫 → 走

每个巡逻者一条航点环线，状态机在 `walk`（走向下一航点）与 `scan`（原地左右扫视）之间切换。
`scan` 是紧张感的来源：玩家必须读出"他现在看向哪、什么时候会转过来"。
**每次重试重新随机**航线（原作 `每次重试随机巡逻`），所以背板子没用，得读现场。

### 电梯：呼叫 → 等 → 进入

第 2、3 关的出口是换层电梯：按 E 呼叫 → 等 `ELEV_WAIT` 秒（这段时间你必须活着）→ 靠近按 E 进入。
原作 `电梯到了才算下班` 说的就是这个：**到了也不算，还得活着走到门口**。

### 限时与结算

三关共用总时限（`normal` 210 秒 / `hell` 150 秒）。
结算 = 通关关数 + 剩余时间，每模式一条赔付阶梯（沿用前两个玩法的经济纪律）。
**入场 ¥20**，中途点「收工」不结算也不收费（与开窗/外卖同口径）。

## 四、验收口径

| 层 | 怎么验 |
| --- | --- |
| 关卡数据 | 三关都能解析；行宽一致、外墙封闭、**每个关卡都恰有一个出生点/出口/文件夹** |
| **可达性** | 从出生点 BFS，**出口与文件夹都必须可达**（否则关卡直接不可能通关） |
| 视线 | `losClear` 对"中间隔着墙/工位/隔板/空地"四种情形逐一验；隔板挡视线但**可以走过** |
| 视野锥 | 角度边界（正好半 FOV 处含等号）、距离边界、遮挡优先于角度 |
| 伪装 | 伪装期间**任何巡逻者都看不见你**；伪装到期后立刻恢复可被发现 |
| 咖啡机 | 启动后相关巡逻者的目标改到茶水间，且**到期后回到原航线** |
| 电梯 | 呼叫 → 等待期间不可进入 → 到达后可进入；未呼叫时按 E 无效 |
| 巡逻确定性 | 同 seed 航线完全相同；换 seed 必须不同；hell 模式巡逻更多/更快 |
| 经济 | 蒙卡：三关全通 vs 只过一关 vs 一动不动的期望收益单调且有界；**不能用时超过时限还赚钱** |
| 实机（无头 Chrome） | 出口可见性 / 画布非空白 / 视野锥真的画出来了 / 被发现的判定与 UI / 三关流程 / 收工释放 |
