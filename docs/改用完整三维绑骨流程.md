# 当前问题与新流程

## 原因

之前的产物是平面图片的变形和裁切，并非完整三维人体的连续蒙皮。增加骨骼名称和数量不能修复肩部体积、腋下遮挡和错误权重。之前的动作验收不充分，代码测试通过不能证明骨骼动画视觉合格。

参考 `D:/下载/绑骨流程.md`，改为：全身 T 姿参考 → 连续三维人物 → v3.0 人形绑定 → 动作重定向及本地关键帧 → 逐帧检查 → 接入游戏。
