# 早餐店 · 学生 3D 动画样板

2026-10-30

## 查看

打开项目根目录的 **早餐人物3D-独立预览.html**。Three.js、人物模型和动画均内嵌在这个文件中，不加载外部图片或网络模型。

默认循环播放双手接餐动作。可以切换自然待机、挥手招呼、双手接餐和着急催餐，拖动旋转、滚轮缩放，查看正面、侧面、背面及半身。支持透视骨骼、线框、暂停和自动旋转。

## 人物与绑定

- 卡通 3D 造型，保留反戴红帽、灰色上衣和双肩包；增加裤子、鞋子、完整双臂、手掌及手指。
- 35 根 THREE.Bone 构成父子骨架，模型部件直接绑定到骨骼，属于分件刚性绑定，不是连续皮肤权重蒙皮。
- 双手接餐时肩、肘、腕联动，托盘位置取双手之间，补偿旋转以保持水平；点头动作由颈部和头部驱动。
- 模型及动作生成入口为 `breakfast-character3d.js`，沿用项目内 Three.js r149。没有修改其他玩法的 Three.js 文件或全局色彩管理设置。

## 游戏接入

主页面会加载 3D 模块。学生顾客改用离屏 WebGL 渲染后合成到原 Canvas 的立体半身人物，文字位置为较大的头像让出空间。收到食物时双手接餐；满意离场继续使用独立气泡。

WebGL 不可用则退回上一版 2D 骨骼动画，再退回原静态/矢量头像。减少动态效果设置会停止人物动态。退出早餐游戏时释放 3D 模型、材质和 WebGL 上下文。

## 修改及验证

修改模型或 `tools/bf/3d-preview.template.html` 后运行：

```
node tools/bf/build-3d-preview.cjs
node --test tests/breakfast-character3d.test.cjs tests/breakfast-rig.test.cjs tests/breakfast.test.cjs
node tools/bf/verify-rig.cjs --3d
```

97 项相关测试通过。真实 Chrome 已验证：独立预览不依赖相对路径、动作切换、前侧后视角、骨骼、手机布局、游戏内真实 3D 绘制、部分上餐与整单完成、减少动态效果、2D 回退。截图在 `dist/breakfast-3d/`。

这是用于判断造型与动作的程序化模型样板，尚未生成 Blender 工程或 GLB。后续可按确认的风格细化脸部与衣服，并增加连续蒙皮及动画文件导出。
