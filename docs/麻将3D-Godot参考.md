# 3D 麻将（Godot 版）→ 网页版移植参考

`reference/mj-godot3d/` 是一套已经跑通的 Godot 4.7 3D 麻将实现。
本文档只提炼**网页版需要对齐的规则与布局**，不要求照搬 GDScript。

对应源码：

| 文件 | 作用 |
|---|---|
| `main.gd` | 场景构建、回合状态机、碰杠胡流程 |
| `rules.gd` | 胡牌判定与算分 |

---

## 一、必须对齐的规则

### 1. 三种杠

| 类型 | 触发条件 | 能否被抢杠 |
|---|---|---|
| **直杠** | 手里 3 张，别人打出第 4 张 | 可（判定顺序：胡 → 杠）|
| **补杠** | 已碰 3 张，自己摸到第 4 张 | **可被抢杠** |
| **暗杠** | 自己摸齐 4 张 | **不可抢** |

补杠实现（`main.gd` 的 `_do_self_kong`）：

```gdscript
if kind == "bugang":
    for 其他三家 s:
        if evaluate(hands[s] + [tile]) 能胡:
            _win(s, tile, ev)   # 抢杠胡
            return              # 杠作废，副露仍是 3 张
    # 无人抢 → 副露 3 张变 4 张，从牌尾补一张
```

关键顺序：**先判抢杠，再执行杠**。抢杠成立时副露保持 3 张。

### 2. 牌墙余牌

一墩 = 上下两张。取牌从破墙处开始，**余牌为奇数时，破墙那一墩只剩下面一张**：

```gdscript
keep = ceil(remain / 2)          # 墩数
for i in keep:
    layers = 2
    if remain % 2 == 1 and i == 0: layers = 1   # 只剩一张
```

这样「画出张数 == 余牌张数」，不会一次少两张。

### 3. 杠后补牌

杠成立后从**牌尾**（wall 另一端）补一张，再从手牌里打出一张。

## 二、必须对齐的四家方位

逆时针出牌：你 → 右 → 对 → 左。

| 座位 | 屏幕位置 | 手牌 | 牌河 | 副露 |
|---|---|---|---|---|
| 0 你 | 下 | z = +392 | z = +160 | 右手边 |
| 1 下家 | **右** | x = +436 | x = +160 | 右手边 |
| 2 对家 | 上 | z = −392 | z = −160 | 右手边 |
| 3 上家 | **左** | x = −436 | x = −160 | 右手边 |

牌面朝向：0°、+90°、180°、−90°（各自的牌面朝向自己）。

> 历史坑：早期版本把 1、3 号位画反了，导致「下家打的牌出现在上家牌河」。
> 网页版请确保**名牌、手牌、牌河、副露四处使用同一套座位映射**。

## 三、回合流程（状态机，不用 await）

网页版建议同样用「状态 + 截止时间」推进，避免异步竞态：

```
HUMAN_DISCARD → CLAIM_WAIT(1.0s) → [胡 > 杠 > 碰] → 下一家
AI_DRAW(1.0s) → AI_DISCARD(1.3s) → CLAIM_WAIT → ...
```

- 出牌后**停 1 秒**再判碰杠：让牌名播报念完、玩家看清是谁打的
- 所有定时用**墙钟**（`Time.get_ticks_msec()`），不要用帧 delta
