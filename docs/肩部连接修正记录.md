# 肩部连接修正

前一版把图像手臂裁开并用圆形贴片覆盖接口，用户指出抬臂会断开。该实现不应作为完成品验收。

当前使用 breakfast-connected-rig.js。骨架由骨盆、脊柱、胸腔、颈部、头部、左右锁骨、上臂、前臂、手腕、手掌和手指层级组成。锁骨随上臂抬起；肩部网格共享顶点，并混合胸腔、锁骨和上臂权重。删除旧的肩部裁切着色器及圆片补缝实现。

当前素材仍是单张正面插画。手指骨骼建立了父子关系，但未单独绘制手指图层或制作独立手指动作。它不是完整三维人体。抬臂连接已有改善，手臂轮廓及遮挡处仍需继续检查和精修；代码测试不能替代目视验收。

参考用户提供的 ActionForge 页面：https://actionforge.app/ 。未导入或复制其人物模型、动画或源代码。

验证：97 项相关测试通过；真实 Chrome 验证预览、动作、游戏内上餐和回退路径。截图在 dist/breakfast-original/，wave.png 为本次抬臂检查画面。
