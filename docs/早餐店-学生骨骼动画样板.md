# 早餐店 · 学生骨骼动画样板

2026-10-30

## 查看效果

直接用浏览器打开项目根目录的 `breakfast-rig-preview.html`。

预览页已内嵌三张人物图片及动画程序，单文件离线或独立预览均可运行，不依赖旁边的素材目录。修改预览时编辑 `tools/bf/rig-preview.template.html`，然后运行 `node tools/bf/build-rig-preview.cjs` 重新打包。

- 默认展示轻微呼吸与转头。
- 点击“着急催餐”查看催餐动作。
- 点击“送上早餐”查看满意换脸和一次点头。
- 可显示骨骼、显示网格、暂停或对比原始静态图片。
- 如果系统启用了“减少动态效果”，默认尊重系统设置。

游戏主页面已加载此模块，学生顾客的头像会自动使用动画。其他四位角色沿用原贴图。

## 实现范围

原 PNG 保持不变。`breakfast-rig.js` 建立身体、头部两根父子骨骼，以 6×16 网格进行三角形纹理绘制，颈部用平滑权重混合。它是运行时的 2D 网格蒙皮样板，不是 Spine 工程，也没有新增可挥动的手臂。

成功上餐记录 `lastFoodAt`，驱动 1.1 秒的一次点头。顾客拿齐订单后，原订单卡照常释放，满意点头在小气泡中播放，随后淡出。错误或烧糊的食物不会触发点头。缺少动画模块时保留静态绘制路径。

头像框仍为 64×68，计分、耐心奖励、订单选择和点击区域保持原规则。由于游戏内头像较小，放大预览页更容易观察头部和身体独立运动。
