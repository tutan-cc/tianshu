## v1.0 更新（打斗系统 + 趣味小游戏）

### 1. 打斗场景怎么"打"——回合制格斗（新玩法）
视频里的打斗不再只是看：新增内嵌精准判定的**回合制格斗**，用在「老城区 · 一打二」（Day6 晚，第一章章末）：
- **你的生命 = 70 + 体魄×1.6 + 装备/等级加成**（练体能真的有收益）
- 每回合 **3 行动力**，招式：直拳(1) / 组合拳(2) / 低扫(2) / 抱架(1，格挡+16) / 读招(1，本回合受伤−25%)
- **对手意图全程明牌**（直拳/连击/抱架/重拳固定轮转），可以靠"读招"打反手
- **带【精准】的招式触发时机判定**：绿区内按下 → 伤害 ×1.9（与前作 QTE 手感统一）
- 失败也不虐主：走"被打倒但没让他们占到便宜"的保底分支

### 2. 麻将（新玩法）
「金色年华 · 麻将局」（Day8 晚）——**真·胡牌判定**（14 张拆成 4 面子 + 1 将，递归求解）：
- 摸牌 → 点手牌打出，能在 **第 5 巡前胡牌**才算赢（金老板第 5 巡必胡）
- 提示按钮花 ¥20；胡牌解锁成就【牌桌老千】

### 3. 刮彩票（新玩法，可重复）
侧栏常驻「🎟 刮刮乐（¥20）」——**Canvas 真刮开**（destination-out 涂层）：
- 鼠标/手指涂抹，刮开 35% 自动揭晓；奖池 ¥0/5/10/20/50/200
- 中奖直接进财富，可反复玩（考验手气与自制力）

### 4. 新增调试入口
标题屏多了「⚑ 跳到打斗」「⚑ 跳到麻将」，配合原有「⚑ 跳到谈判」，三个新玩法都能一键直达。

## v0.9 更新（谈判博弈：把 tianshu 的 combat 改成话术对决）

- **新玩法「合同谈判」**（Day9 上午 · 金色年华合同桌）：每回合 3 行动力，三张话术牌
  - **施压**（2 行动力）：对手底线 −14，但消耗 2 筹码
  - **让利**（1 行动力）：底线 −4，筹码 +1
  - **试探**（1 行动力）：底线 −2，**预判对手未来 2 步意图**
  - 对手招式固定轮转且**全程明牌**：抬价 −3 / 拖时间 −2 / 反压 −4 / 摊牌 −5（消耗你的筹码）
  - 胜负：把对手底线压到 **20 以下**即成交；筹码归零则谈崩（保底收益，不虐主）
- **羁绊直接接入玩法**（这正是它和我们系统最配的地方）：
  - 红姐羁绊 ≥20 → 她给的内幕变成 **开局筹码 +3**
  - 顾曼羁绊 ≥20 → 她的背书 **对手底线 −8**
  - 面板上会写明本次享受了哪些羁绊加成
- 节点 16 → **17**，玩法 7 类 → **8 类**；新增成就【谈判高手】

## v0.7 更新（配音换成"演员本人原声"）

上一版用系统 TTS 合成，太生硬、念稿感重。这一版改成：

1. **角色台词用素材里演员本人的原声**：素材库本就按人物分类（女房东/跑步女孩/女同事/图书馆/拳击教练/酒吧老板娘/妹妹/女护士/女老板/NPC），
   所以从对应分类的原始视频里**定位真正的说话片段**（ffmpeg `silencedetect` 找语音区间 + 响度归一 + 首尾淡化），
   抽出来当该角色的配音 —— **声画同一个人，语气情绪都是真人的**
   - 23 条角色台词已全部替换为真人原声（`audio/vo_real/`，436KB）
2. **旁白改为分句合成**：按标点切句、逐句合成、句间插入 110–210ms 停顿、语速轻微起伏，去掉念稿感（`audio/vo/`）
3. **三态配音开关**：右上角 🎙 循环切换 **真人原声 → 合成语音 → 关闭**；真人原声缺失时自动回落到合成语音

> ⚠ 一个必须说清的取舍：真人原声片段说的是**素材里的原台词**，与我们字幕的文字并不一致。
> 这是"要真人语气"与"要台词精确"之间的必然取舍：当前把字幕作为权威文本，原声作为**人声质感**。
> 如果更想要"台词逐字被念出来"，切到「合成语音」模式即可。

## ⚠ 看不到画面？先看这里

1. **不要在压缩包里直接打开**：Windows 允许你双击 zip 里的 `index.html`，但那样**只有一个文件被解压到临时目录**，`video/` 找不到 → 黑屏。
   → 请**先把 zip 解压到文件夹**，再双击里面的 `index.html`。
2. 确认 `index.html` 同级有 `video/` 目录（内含 35 个 mp4 + `poster/` 剧照）。
3. 用 **Chrome** 打开（右键 → 打开方式 → Google Chrome）。
4. 若仍无画面，游戏会**自动弹出诊断面板**并说明原因；即使视频全部不可用，也会用**剧照 + 动态推移**继续演剧情，流程照样能打通。

## 运行方式

**直接双击 `index.html`**（用 Chrome 打开）即可游玩，无需服务器、无需联网。

如浏览器对本地视频有限制，可用本地服务器方式打开（在**仓库根目录**下执行）：

```
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000/index.html
```

> 素材（`video/` `audio/`）不入 git 仓库。clone 后需下载素材包并跑一次 `link-media.ps1`，
> 详见 **[协作者上手指南.md](协作者上手指南.md)**。
> ⚠ `http.server` 会把整个目录暴露出去（含 `tools/`），仅限本机自用，勿对外开端口。

## 操作

- 标题屏点击【开始重生】→ 自动进入序章
- 镜头播放 4.5 秒后出现【继续 ▸】，点击或按空格推进；【跳过本节点 ≫】直达交互
- 选择类节点：点击选项，数值即时反馈（右上角 toast）
- 答题：限时 12 秒/题（图书馆·讲题三连 / 投资大厦·风口三连问 两套题库）
- QTE：拳击馆【时机判定】（空格/点击，体魄加宽绿区）；KTV【拼酒连打】（6 秒狂点）
- 小游戏：老城区【数据洪流·躲】（←→ 或鼠标移动躲 12 秒）；投资大厦【股市波段】（六日买卖决策，Canvas K 线）
- 右上角 ♪ 可开关程序化 BGM；🎙 可开关台词配音
- 点击画面任意处 = 跳过当前语音；主沙盘点击发光地点进入下一节点；自动存档（localStorage）

## v0.5 更新（配音！）

你问的"只有 BGM 没有台词"——现在补上了**离线中文配音**：

1. **40 条台词全部有配音**（`audio/vo/*.mp3`，共约 3.3MB）。用 Windows 自带 SAPI 语音引擎离线合成，**零依赖、零成本、可批量重生成**
